# Security

Report a vulnerability privately: open the repository's Security tab and choose
[Report a vulnerability](https://github.com/raulcorreia7/bof3/security/advisories/new).
Do not open a public issue for it. Include the affected file or command and the steps to reproduce.

This repository holds the workspace `Makefile`, its scripts and the install scripts in
`tools/install/`. A problem in a member project belongs in that project's repository.
