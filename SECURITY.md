# Security policy

Report a vulnerability privately: open the repository's Security tab and choose
[Report a vulnerability](https://github.com/raulcorreia7/bof3/security/advisories/new).
Do not open a public issue for it. Include the affected file or command and the steps to reproduce.
Do not attach game data.

## Scope

The workspace `Makefile`, its scripts and `tools/install/dprint.sh` download and run tools; a flaw in them is in scope. A problem in a member project belongs in that project's repository.

## Supported versions

The latest release and `main`.
